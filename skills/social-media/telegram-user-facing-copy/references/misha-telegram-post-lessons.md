# Misha Telegram post lessons

Condensed lessons from a session about Telegram image posts and story-style captions.

## Durable preferences captured

- User wants one best final option by default, not a menu of alternatives.
- User-facing Telegram copy should arrive as a finished artifact, not wrapped in labels or technical scaffolding.
- Example phrasing from the user is a direction, not text to mirror back.
- If the user asks for a post "под ключ", compose the full final post independently.

## Caption-specific lessons

- Check whether the caption refers to anything actually present in the image.
- If the image is atmospheric rather than object-rich, write to mood and pace, not to invented scene details.
- Prefer ordinary Russian phrasing over abstract concepts like "новый взгляд на свой мир" unless the visual clearly supports that tone.
- When in doubt, simpler and more spoken beats more poetic.

## Failure modes seen in practice

- Raw media/delivery notation leaked into the user-visible message.
- The copy leaned too philosophical for the image.
- The wording reused the user's rough phrase too closely instead of resolving it into a natural caption.

## Better target style for this case

- Short
- calm
- human
- visually coherent
- ready to paste/send as-is
