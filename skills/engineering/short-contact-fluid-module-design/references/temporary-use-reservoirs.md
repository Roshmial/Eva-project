# Session note: temporary-use shower reservoirs vs storage bottles

Key learning from this session:
- The user did not need true storage bottles.
- The real requirement was a short-contact fill reservoir for hot and cold water, especially hot water poured from a kettle.
- That changes the architecture materially: temporary-use insertable reservoirs are a better fit than premium external lab bottles.

Engineering implications:
- Reservoir requirements should be set by fill/use/wash cycle length, not by storage assumptions.
- Short-contact hot-water use shifts attention from long-term container quality to:
  - thermal tolerance during the use window;
  - safe fill-from-top workflow;
  - stable seating in the carrier;
  - lower wet-interface safety;
  - keeping the hot path non-printed up to the mixing point.
- A carrier-style frame with bottom support, side guides, and top strap broadens compatible cheap containers and reduces redesign cost.

Cost lesson:
- Lab bottles can dominate BOM cost without adding proportional value for short-contact prototypes.
- Before recommending branded lab containers, test whether generic containers, cups, or metal inserts satisfy the real usage pattern.
