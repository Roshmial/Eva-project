# When to use
Use when the user asks for:
- text for a presentation or slide;
- a short market/system/vendor comparison to paste into PPT/DOCX;
- a concise list of platforms/products/cases with links;
- an executive summary where over-expansion harms readability.

## Core rule
Default to a **one-slide-first** delivery unless the user explicitly asks for a deck, several slides, or a detailed appendix.

# Output shape
1. Give a short title or framing sentence.
2. Give 3-5 compact bullets or 1 short paragraph plus bullets.
3. If products/systems are listed, add vendor links inline or as a short link list.
4. Keep wording presentation-safe: short, precise, and defensible.

# Scope discipline
- Do not call a list "full" unless it was actually verified as market-complete.
- Prefer labels such as "топ-5", "ключевые", "наиболее релевантные", or "подтвержденные в открытых источниках".
- If evidence is partial, say so briefly and move on.

# Comparison rules for systems/platforms
When comparing systems:
- separate **specialized performance/KPI systems** from **broader HR/HCM cores with KPI features**;
- avoid duplicative confusion such as treating a specialized add-on and a base HR core as the same class;
- if a product is retired/discontinued, flag that clearly before including it in a top list;
- prefer current vendor pages over secondary rankings when validating product existence.

# Evidence rules
Split mentally into:
- confirmed facts from vendor or credible project/case source;
- reasonable interpretation;
- unknown / not publicly confirmed.

Never upgrade "mentioned in a conference note" into a fully documented case with proven outcomes.

# User-specific delivery lessons embedded
For this user, poor delivery patterns in this task class were:
- expanding a one-slide ask into a 10-slide structure;
- labeling a shortlist as "full" without verifying the market;
- leaving product-class distinctions implicit and creating confusion.

Corrective behavior:
- compress first;
- state scope honestly;
- explain class distinctions in one sentence when similar products appear side by side.

# Example micro-template
Заголовок: <1 sentence>

Краткий ввод: <1-2 sentences on what this class of systems gives the business>

Топ-системы:
- <system 1> — <5-10 words of why it matters>
- <system 2> — <5-10 words>
- ...

Сноска по охвату:
- Список отражает <top/key/relevant/confirmed> решения и не претендует на полный рынок без отдельной верификации.
