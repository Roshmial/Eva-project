# Gamma targeted deck edits

- Treat an approved Gamma deck as the primary artifact; change only named slides or elements.
- Do not regenerate an entire presentation for a local correction unless the user explicitly asks for a new storyline or visual concept.
- Before changing a deck, identify the exact Gamma document and slides, then use an edit/update API or the interactive editor where available.
- Preserve source slides that the user requested to keep unchanged, including copied appendix slides.
- Keep no more than two active versions. Archive a superseded version only after the replacement is verified.
- Verify the edited presentation after export: slide count, 16:9 ratio when required, named corrections, and absence of prohibited brands.
- Mark historical examples and metrics as historical; never present them as guaranteed results.
