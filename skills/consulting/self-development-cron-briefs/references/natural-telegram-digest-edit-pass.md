# Natural Telegram digest edit pass

Use this reference when the daily/weekly brief starts sounding generated even though the structure is formally correct.

## Session-derived corrections

From the July 2026 digest tuning loop with Misha:
- The user cared less about changing the task list itself and more about making the wording feel live.
- The failure mode was not factual wrongness; it was delivery texture: too polished, too symmetrical, too obviously generated.
- Old working versions were better because they sometimes included concrete links to routes, music, YouTube, films, or events, not only planning bullets.

## Strong negative signals

Treat these as rewrite triggers:
- phrases that sound like planning software: `главный рабочий блок`, `собрать базу`, `отдельно собрать`;
- fake optimization language: `выдели 20–30 минут`, `один блок`, `одна мелочь`, `ровно 10 минут`;
- explanatory filler after a recommendation: `... просто переключить голову`, `... чтобы не ...`, `... без ...`;
- contrastive framing: `..., а не ...`;
- over-neat symmetry where every line has the same shape and tone.

## Better direction

Prefer short live-chat wording such as:
- `можно вечером пройтись рядом с домом`;
- `проверь билеты и брони`;
- `если будет настроение, включи что-нибудь новое`;
- `я бы сегодня закрыла ...`.

## Editing rule

After drafting, read the message once as if it just arrived in Telegram from a familiar person.

If a line feels like something nobody would type quickly by hand, rewrite it shorter.
If a phrase explains too much, cut the explanation.
If two versions mean the same thing, keep the simpler one.

## Richness reminder

A good digest does not have to stay inside `tasks + prep`.
When relevant, it can carry one concrete link to:
- a route;
- a music item;
- a YouTube video;
- a film or episode;
- an event.

That richness often makes the brief feel more alive than further prompt-level polishing.
