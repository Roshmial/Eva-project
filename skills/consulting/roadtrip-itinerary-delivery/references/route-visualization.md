# Визуализация автомобильного маршрута

Используй этот файл как короткую памятку, когда пользователь уже согласовал каркас автопоездки и просит показать маршрут визуально.

## Принцип

Сначала визуализируй текущий согласованный маршрут, а не перепроектируй его.

## Предпочтительный порядок

1. Ссылка на маршрут целиком.
2. Если единая ссылка не получается или становится неудобной, дай ссылки по сегментам.
3. Если картографический сервис не подходит, собери простую схему: города по порядку, даты, ключевые перегоны.

## Что подписывать рядом с картой

Достаточно 1 строки на сегмент:
- дата;
- откуда → куда;
- при необходимости пометка "тяжёлый перегон".

## Практический шаблон ответа

Если пользователь просит: "построй визуально", "покажи на карте", "сделай схему маршрута", по умолчанию отвечай в таком порядке:
1. сама визуализация: ссылка на карту, набор ссылок по сегментам или простая схема;
2. короткая расшифровка по дням в 3–7 строк;
3. при необходимости — отдельное предложение потом собрать подробный гид по точкам.

То есть визуальный запрос имеет приоритет над повторным обсуждением логики маршрута.

## Фолбэк, если единая карта неудобна

Если не получается быстро дать одну стабильную ссылку на весь маршрут:
- не зависай на попытке собрать "идеальную" карту;
- сразу давай маршрут по сегментам;
- добавляй простую линейную схему вида:
  Москва → Липецк → Волгоград → Астрахань → Волгоград → Воронеж → Москва.

Это лучше, чем снова уходить в длинное текстовое обсуждение.

## Чего не делать

- Не превращать запрос на карту в новый длинный разбор логистики.
- Не открывать заново спор о промежуточных городах без новых данных.
- Не перегружать карту десятками второстепенных точек, если пользователь просил именно маршрут, а не полноценный гид по остановкам.
