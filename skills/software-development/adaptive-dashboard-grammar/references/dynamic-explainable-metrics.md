# Dynamic explainable metrics for dataset dashboards

## Когда это применять

Использовать, когда dashboard строится по табличному dataset и пользователь ожидает не просто визуализацию, а понятные человеку показатели с коротким объяснением смысла.

Особенно важно для:
- it_analytics
- security
- operations
- support
- finance

## Ключевой урок

Антипаттерн: `главная метрика = имя числовой колонки` + generic bar chart.

Правильный подход:
- вывести user-facing label;
- дать значение в понятном формате;
- добавить `note`, который объясняет, что показывает метрика и как её читать;
- по возможности вывести derived metric или динамику, а не только raw field summary.

## Хорошие паттерны

### Для summary cards
- `Инциденты` — не `incident_count`
- `Средняя доступность` — не `uptime`
- `Типичная задержка` — не `latency_ms`
- `MTTR` / `Среднее время восстановления` — не `mttr_hours`
- `Бэклог уязвимостей` — не `vulnerability_count`
- `Покрытие контролей` — не `control_coverage`
- `Средний риск-уровень` — не `risk_score`

`note` у card должен отвечать хотя бы на один вопрос:
- что это значит;
- почему это важно;
- как интерпретировать больше/меньше.

### Для sections
- у визуального блока должен быть `note`, который объясняет, что пользователь должен увидеть в графике;
- временной ряд нужен, если есть period/date/time поле;
- распределение по severity/priority нужно, если есть security-criticality поле;
- профиль производительности должен показывать не только среднее, но и тяжёлый хвост / пики деградации.

## Best-effort derivation

Если нет canonical KPI:
- использовать честный proxy;
- явно обозначать его как proxy или approximation;
- не превращать proxy в псевдоофициальную метрику.

## Минимальный стандарт качества

Дашборд по dataset не должен оставлять пользователя один на один с сырым названием колонки.

Минимум:
- 1–3 user-facing cards;
- хотя бы 1 explanatory note в cards;
- хотя бы 1 explanatory note в sections;
- хотя бы 1 dynamic section по временному ряду, распределению или профилю, если данные это позволяют.
